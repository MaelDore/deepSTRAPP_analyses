AnalysisScript.R:
The analysis R script used in analysis

Armenta_data.txt:
Bird reflectance-based dichromatism measurement published by Armenta et al. 2008

birds_hackett.tre
Bird phylogeny, the MCC tree with Hackett backbone and with only species that have genetic data published by Jetz et al. 2012


fish2cr_event_data_250m.csv
BAMM event data file, BAMM diversification output with fish phylogeny (used in Rabosky et al. Nat com. paper)

fish_naturecomm.tre
Fish phylogeny used in Rabosky nat. com. paper

fishsize_event_data.txt
BAMM trait output on fish body size evolution

fishtree_morph.txt
fish phylogeny with taxa that have morphology measurement

hack2vr_event_data_250m.csv
BAMM diversification analysis output with bird phylogeny

traitDependentBAMM.R
the R function for STRAPP analysis, now included in the BAMMtools package.
